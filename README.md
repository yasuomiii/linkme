# Meine Link-Seite

- `index.html` und `assets/`: die öffentliche Link-Seite (Platzhalter, wird durch deinen Export ersetzt)
- `editor/index.html`: dein persönlicher Editor (Link Studio)

## Einrichten
1. Alles aus diesem Ordner in ein GitHub-Repository hochladen (Ordner `editor` und `assets` mit).
2. Settings > Pages: Branch `main`, Ordner `/ (root)`.
3. Editor öffnen: https://DEINNAME.github.io/REPO/editor/ (bei Repo-Name DEINNAME.github.io entfällt /REPO).
4. Im Editor gestalten, dann Exportieren > "Einzelne Datei" und die erzeugte `index.html` im Hauptordner des Repos ersetzen.

Der Editor speichert deinen Stand im Browser. Sichere ihn über Optionen > Projekt sichern.
